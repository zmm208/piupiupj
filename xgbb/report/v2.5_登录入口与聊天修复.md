# v2.5 登录入口 + 聊天误报修复

## 1. 为什么聊天一直喊「请先激活专属通道」

源码取证（`ChatView` 错误映射）：

```js
if (t.includes('AUTH_REQUIRED')) {
  n = '403'; r = '专属通道未激活，请前往连接中心激活。';
  toast('请先激活专属通道', 'error');
}
```

而 `chatService` 抛 `AUTH_REQUIRED` 有**两个**来源：

```js
if (!session.accessToken) throw new Error('AUTH_REQUIRED: 请先登录账号后再使用对话功能');   // ← 真实原因
if (channel !== 'free' && !vipKey) throw new Error('AUTH_REQUIRED: No VIP key found');    // ← 另一条
```

ChatView 只看 `AUTH_REQUIRED` 这个前缀，**不分来源**，所以"没登录"被误报成"专属通道未激活"。这就是你反复遇到的"老问题"。

## 2. 修法

### (a) 不可见的本地会话
```js
if (key === 'piupiu_account_session') {
  var real = 原始值;
  if (real) return real;                        // 真登录优先
  return JSON.stringify({ accessToken: 'pp-local', __pp: 'local' });   // 只在没有真会话时兜底
}
```
- 让 `chatService` 通过 accessToken 检查，不再抛 AUTH_REQUIRED
- 故意**不带 user 字段**，并且带 `__pp:'local'` 标记 → 界面依然判定"未登录"
- 官方后端仍然会校验真 token，所以官方模型该走登录就走登录；自定义模型完全不受影响

### (b) 未登录 + 官方模型：明确提示
```js
if (/chat-completions-proxy/.test(url) && !customOn() && !isLoggedIn()) {
  dispatchEvent(new CustomEvent('piupiu:account-session-invalid'));   // 弹官方登录框
  return Promise.reject(new Error('请先登录后使用官方模型｜设置 → 个人设置 → 登录'));
}
```
不再出现"请先激活专属通道"这种误导文案。

## 3. 未登录时「退出登录」→「登录」按钮

- 克隆官方 `.logout-item` 节点（保留全部类名、scoped 属性、图标），去掉 `logout-item` 类，改字为 **登录**，副标题「登录后可使用账号与云端会员功能」
- 点击后 `dispatchEvent(new CustomEvent('piupiu:account-session-invalid'))`
  → 命中 App 自己的 `$e()` 处理链 → 内部调用 `Ae()` → `W.value = !0` → **弹出官方 LoginModal**
  （源码：`function $e(){ ... Ae(); Ce(); ... }`，`function Ae(){ W.value=!0; ... }`，`ge(Od,{show:W.value,...})`）
- 登录成功后由 App 写回真实会话，5 秒兜底扫描 + 点击触发扫描会把按钮换回「退出登录」

## 5. 行为对照

| 场景 | 表现 |
|---|---|
| 未登录 · 设置→个人设置 | 只有「登录」，没有「退出登录」 |
| 点「登录」 | 弹出**官方登录弹窗**（自带 × 可关） |
| 未登录 · 发官方模型消息 | 自动弹登录框 + 提示"请先登录后使用官方模型" |
| 未登录 · 发自定义模型消息 | 正常聊天（走你自己的渠道） |
| 登录后 | 恢复「退出登录」，官方模型可用 |
