# v2.5 实机（浏览器）验证与三处修复

## 这次先做了实测
把构建目录用 HTTP 服务起来，用无头 Chromium 真跑了一遍前端（守卫脚本注入 head），
在浏览器里复现并验证了每个问题，不再靠猜。

## ① 「请先激活专属通道」——真因抓到了

`ChatView` 的错误映射：
```js
if (t.includes('AUTH_REQUIRED')) toast('请先激活专属通道', 'error');
```
`chatService` 在**没有登录**时抛 `AUTH_REQUIRED: 请先登录账号后再使用对话功能`，
被这段映射统一显示成"专属通道未激活"。

更深一层：我上一版加的请求拦截分支写了 `!customOn()`，但 **`customOn` 这个函数根本不存在**，
抛出的 ReferenceError 被外层 `try/catch` 吞掉 → 拦截逻辑整段跳过 → 请求直接打到服务器 → 401 → 误报。

修法：
1. 补上 `customOn()`（`S.customOn && S.models.length && curModel()`）
2. 未登录 + 官方模型 → 拦截并返回明确文案，同时弹官方登录框：
   ```
   请先登录后使用官方模型｜设置 → 个人设置 → 登录
   ```
3. `fetch` 钩子改成**可重装**（Capacitor 可能覆盖 `window.fetch`），扫描时发现被覆盖就重装

浏览器实测结果：
```
fetchName: ppFetchWrapped          ← 钩子生效
chatErr  : 请先登录后使用官方模型｜设置 → 个人设置 → 登录
modals   : 登录 PiuPiu 账号 / 邮箱 / 密码   ← 官方登录框已弹出
```

## ② 设置页「退出登录 / 登录」提前判断

不再等扫描后再改 DOM，而是**脚本加载时**就给 `<html>` 打标记：
```js
document.documentElement.classList.toggle('pp-logged-in',  logged);
document.documentElement.classList.toggle('pp-logged-out', !logged);
```
CSS 直接控制显隐：
```css
.logout-item{display:none!important}
html.pp-logged-in .logout-item{display:flex!important}
#pp-login-item{display:none!important}
html.pp-logged-out #pp-login-item{display:flex!important}
```
→ 进入设置页瞬间就是正确 UI，不会先闪一下「退出登录」。

实测：`htmlCls = "hydrated pp-logged-out"`，`.logout-item` display:none，#pp-login-item display:flex。

## ③ 点「登录」为什么不弹面板

上一版把假会话**全局**返回，App 认为已登录 → 点登录派发 `account-session-invalid` →
`$e()` 走"会话失效"分支，只弹提示「登录已失效，请重新登录」，登录框被状态覆盖掉。

现在假会话**只在 chatService 调用栈里**出现（`/chatService/i.test(stack)`），
其它任何地方都返回真实值。实测点击后：
```
modals: [{ text: "登录 PiuPiu 账号 邮箱 密码 登录 注册账号 · 忘记密码 ×" }]
```
官方登录弹窗正常打开（× 可关）。

## ④ 卡密提前校验 + 清空

1. **读取时不给假卡密**：`piupiu_app_vip_key` 在 `ConnectionView` 调用栈里只返回真卡（无则 null）
2. **启动清理历史遗留**：老版本把哨兵写进过 localStorage，启动时发现等于哨兵就删掉
3. **进入连接中心主动校验**：`check_token.php?key=...`，失败则清空
   `piupiu_app_vip_key / vip_level / vip_expiry` 并提示「卡密已失效，已自动清除」

实测连接中心：
```
卡密输入框: value = ""   ← 不再显示假卡密
状态: 已激活尊享服务 · SSVIP · 有效期至 永不过期
```
