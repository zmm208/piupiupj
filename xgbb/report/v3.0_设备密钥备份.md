# v2.6 设备密钥备份系统

## 一、密钥（只在原生层算，永不落盘）

```
指纹 = "PPK1\0" + ANDROID_ID + Build.FINGERPRINT + BOARD|BRAND|DEVICE|HARDWARE|MODEL|MANUFACTURER|PRODUCT
       + SUPPORTED_ABIS + 包名 + 屏幕宽高@密度
IKM  = SHA-256(指纹)
K64  = IKM 前 8 字节 → 16 位十六进制        （界面上显示的「设备密钥」，同一台机永远一致）
AES  = HKDF-SHA256(IKM, salt="piupiu-backup-v1", info="pp-backup-aes") → 256 bit
```

- 每次加密/解密**现算现用**，`Arrays.fill(0)` 清零；不进 JS 堆、不写文件、不写日志
- 对外只暴露 `K64`（`backupKeyId()`），JS 拿不到 AES 密钥
- 加密：`AES-256-GCM`，随机 12B IV，AAD = `pp-backup-v1|<K64>`

## 二、目录与文件

```
/storage/emulated/0/piupiupj/
├─ 说明.txt          "这是piupiu插件版的备份数据禁止删除"
└─ piupiupj.json     分片密文（行式，便于增量改一行）
```

`piupiupj.json` 结构：

```json
{"v":2,"kid":"a1b2c3d4e5f60718","ver":"2.6","updatedAt":1732…,"sections":{
"cards":"iv.ct",
"settings":"iv.ct",
"vip":"iv.ct",
"chat:12":"iv.ct",
"chat:13":"iv.ct"
}}
```

每个 section 独立加密 → 改一个对话只重加密那一段，其余行原样保留。

## 三、权限
- Android 11+：`MANAGE_EXTERNAL_STORAGE`（首次点备份会跳系统设置，允许「所有文件访问」）
- Android 10-：`WRITE_EXTERNAL_STORAGE` + `requestLegacyExternalStorage`
- 未授权时卡片上会显示「缺少存储权限」，点击按钮自动拉起系统授权页

## 四、备份内容
| 段 | 内容 | 时机 |
|---|---|---|
| `cards` | `roles` / `world_books` / `role_tags` 全表 | 手动全量 |
| `chat:<id>` | 单个对话的 session + 全部消息 + 媒体引用 | **退出该对话时自动** |
| `settings` | `piupiu_*` 本地配置（含 API 配置、预设） | 配置变更时自动（1.2s 防抖） |
| `api` | 自定义模型列表 / 当前模型 / 渠道开关 | 配置变更时自动 |
| `vip` | **只存真卡密**（哨兵/假卡密跳过） | 手动全量 |

「PiuPiu酱」官方默认卡不导出（按 `roles` 里的默认记录过滤，后续可加 id 白名单）。

## 五、恢复
- 入口：①设置卡「恢复备份」 ②**版本变化后启动时自动弹一次**
- 弹窗两种模式：**合并** / **覆盖**
- 恢复走 `INSERT OR REPLACE`（按主键合并），配置写回 `localStorage`，完成后自动重载

## 六、更新弹窗
官方更新提示里新增 **「先手动备份」** 按钮，备份完自动关闭弹窗。

## 七、验证
```
apktool 构建通过；签名 verified=true / v2=true / v3=true
manifest: MANAGE_EXTERNAL_STORAGE / requestLegacyExternalStorage="true"
classes3.dex: BackupStore / backupEncrypt / backupWrite 均在
浏览器冒烟：备份卡渲染正常、恢复弹窗可开、无 JS 报错
```

## 八、已知边界（下一轮补）
