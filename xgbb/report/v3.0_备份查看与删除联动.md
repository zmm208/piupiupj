# v3.0 备份查看器 + 删除联动

## 1. 去掉「打开备份目录」
按钮换成 **「查看备份内容」**（`#pp-bk-view`）。`backupOpenDir` 原生方法保留但界面不再调用。

## 2. 查看备份内容（解密后分板块）
底部大抽屉 `#pp-bkview`，按板块分组：

```
角色卡 · N        ← card:<id>，显示角色名、段名、有没有图
聊天 · N          ← chat:<id>，显示标题、消息数、媒体数
配置类（锁定）
  世界书 / 角色标签索引   cards
  预设与本地配置          settings
  数据库设置表            dbsettings
  自定义模型 / API        api
  卡密（真卡）            vip
```

- 每一条都是**实时解密**后展示（不解密不显示）
- 角色卡、聊天右侧有「删除」按钮，点一下就从备份里删掉并立即落盘
- **预设 / 卡密 / API / 世界书 / 配置类不提供删除按钮**，显示「锁定」，避免恢复后缺项
- 暗色模式已适配

## 3. App 内删除 → 询问是否同步删备份
- 启用备份时记录当前角色 id / 会话 id 集合
- 每次变动检测（20s 轮询）比对：如果发现某角色/对话在 App 里被删了、而备份里还在 → 弹窗：

```
检测到你删除了 2 个角色卡、1 条聊天，备份里还保留着这些内容。
要一起从备份里删掉吗？默认保留。
[保留备份]  [一起删除]
```

- 默认**不自动删备份**，必须你点「一起删除」
- 点「一起删除」只删对应的 `card:<id>` / `chat:<id>` 段，其它段不动
