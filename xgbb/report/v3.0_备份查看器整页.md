# v3.0 备份查看器改为整页三栏

## 为什么之前「查看不了」

排查发现 `bkViewer` **函数本体被之前的批量清理误删了**（只剩按钮里的调用），
所以点「查看备份内容」调用的是 undefined —— 界面毫无反应。

已重新写回完整实现。

## 现在的查看器

整页（`position:fixed;inset:0`，不是底部抽屉），顶部三个 tab：

```
‹  备份内容                    2026-11-27 12:15
[ 角色卡 12 ]  [ 聊天 8 ]  [ 其他 5 ]
```

### 角色卡
每条显示：
- **封面图**（`data:image/png;base64,…`，来自备份里的原始 PNG）
- 名称 / ID / 类型（single/group）/ 官方或自定义
- 角色卡更新时间
- **备份时间**（红色小字）
- 描述摘要（前 90 字）
- 右侧「删除」

### 聊天
列表每条：**对话标题 + 所属角色名 + 消息数 + 媒体数 + 备份时间**。
点「查看」进入详情页：
```
‹ 第三夜的对话
芙蕾雅 · 12 条消息 · 备份于 2026-11-27 11:40

  [我]   …
  [芙蕾雅] …（完整内容，最多 3000 字/条）
```
返回按钮回到列表；右侧「删除」可删单条备份。

### 其他
`世界书 / 角色标签`、`预设与本地配置`、`数据库设置`、`自定义模型 / API`、`卡密`
每个板块显示 **备份时间** + 完整 JSON（`JSON.stringify(data, null, 1)`，最多 8000 字，
可滚动查看，API 的 models / key / base 全都在里面）。

## 保留的行为
- 角色卡 / 聊天可单条删除；配置类（预设 / API / 卡密 / 世界书）显示但锁定
- 解密失败的段会标红「无法解密」
- 深色模式全适配（背景 `#15161a`、卡片 `#1a1b21`、气泡粉/白）
