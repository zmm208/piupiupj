# v3.0 恢复弹窗：缩略图 / 角色名 / 首句预览 / 备份时间

## 角色卡条目

```
[✓] [缩略图]  芙蕾雅
              自定义 · single
              备份于 2026-11-27 12:40
```

- 左侧 **44×44 缩略图**：用备份里的原始 PNG（`data:image/png;base64,…`），没图显示「无图」
- 名称：优先 `role_name`，取不到再显示「角色卡 #id」
- 副标题：官方/自定义 · 角色类型
- 右下角 **备份时间**

## 聊天条目

```
[✓] [角色缩略图]  第三夜的对话
                  芙蕾雅 · 12 条
                  「我今天不想出门…」
                  备份于 2026-11-27 12:41              [预览]
```

- 左侧缩略图 = **这条聊天所属角色卡**的图（找不到就显示「聊」）
- 标题：会话标题
- 第二行：**角色名 + 消息条数**
- 第三行：**用户说的第一句话**（取 role=user 的第一条，压成一行、最多 60 字）
- **备份时间**
- 右侧「预览」→ 打开整页聊天预览（气泡样式，可滚动看完整内容，确认是不是想要的那条）

## 性能

两个列表都是**渐进式解密**：

- 弹窗先出骨架（占位「…」/「加载中…」+ 复选框 + 备份时间）
- 每 16 ms 解密一条并就地填充，主线程不阻塞
- 单条解密失败只在该条显示「无法解密」

实测：打开弹窗 **352 ms**，零 JS 报错。

## 数据结构

- 时间戳来自 `meta` 段（每次写入段时记录 `Date.now()`）
- 聊天所属角色：`session.role_id` → `card:<role_id>` 段里的 `row.role_name`
- 首句：`messages` 中首个 `role === 'user'` 的 `content`
