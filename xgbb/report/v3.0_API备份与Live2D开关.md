# v3.0 API 备份回归 + Live2D 开关

## 1. API 又备份不上了

原因：上一版把备份切到「原生直读数据库」后，新函数 `bkBackupFromDump()` 里**漏写了 api 段**
（插件路径有、直读路径没有），所以聊天正常了、API 却丢了。

修复：直读路径补上

```js
if (S.models && S.models.length) {
  bkPut('api', { models: S.models, curId: S.curId, customOn: S.customOn, aiId: S.aiId });
}
```

现在两条路径（原生直读 / 插件兜底）都会写 api 段，自动备份里也保留一份。

## 2. Live2D：加开关，默认关闭

模型显示不出来，先在界面上关掉；资源文件仍留在 APK 里，随时能开回来。

- 位置：设置 → 个人设置 → 扩展功能 → **「显示 Live2D 模型」**
- 默认 **关闭**（`pp_live2d_off = '1'`）
- 关闭时给 `<html>` 加 `pp-live2d-off`：

```css
html.pp-live2d-off #live2d,
html.pp-live2d-off .live2d-viewer,
html.pp-live2d-off [class*="live2d"],
html.pp-live2d-off [class*="Live2D"] { display: none !important; }
```

打开开关 → 刷新页面即可恢复。

> 说明：这只是隐藏、不渲染，`live2d/` 与 `lib/pixi.min.js`、`lib/cubism4.min.js` 都还在 APK 里。
> 如果你要的是「从安装包里彻底删掉 Live2D」——那是删资源+改代码引用，告我一声我一起做。
