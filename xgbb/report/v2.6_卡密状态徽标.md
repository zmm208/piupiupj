# v2.6 卡密页左上角：三态徽标（绿标必须服务端校验通过）

## 三态定义

| 状态 | 触发条件 | 外观 |
|---|---|---|
| **真卡密 · 已验证**（绿） | 本地有真卡 **且** `check_token.php` 返回成功 | 底 `rgba(22,163,74,.12)` 字 `#16a34a`，暗色 `#4ade80` |
| **卡密待验证…**（灰） | 本地有真卡，但本次会话还没拿到服务端结果 | 底 `rgba(120,120,128,.12)` 字 `#6b7280` |
| **假卡密 · 本地解锁**（粉） | 没有真卡（走哨兵本地解锁），或服务端判定无效 | 底 `rgba(233,121,152,.13)` 字 `#c65378`，暗色 `#f78cab` |

判定代码：
```js
function cardStateOf(key) {
  if (!key || key === FREE_KEY) return 'fake';
  if (CARD_VERIFY.key === key && CARD_VERIFY.ok === true)  return 'real';
  if (CARD_VERIFY.key === key && CARD_VERIFY.ok === false) return 'fake';
  return 'pending';                       // 有卡但未验证 → 灰
}
```

## 校验流程
进入连接中心时：
1. 读到真卡 → 先显示 **灰「卡密待验证…」**
2. 请求 `https://www.piupiuchan.top/check_token.php?key=...`
3. 成功 → **绿「真卡密 · 已验证」**
4. 失败 → 清空 `piupiu_app_vip_key / vip_level / vip_expiry`，提示「卡密已失效，已自动清除」，徽标转 **粉**
5. 网络异常 → 保持 **灰**，下次进页面再试（30 秒节流）

## 实测（浏览器）
```
写入 sk-invalid… → 徽标 pending「卡密待验证…」
服务端判定无效   → 徽标 fake「假卡密 · 本地解锁」
存储             → 卡密已被清空
```
绿色态需要真卡，逻辑同上，校验成功即置 `CARD_VERIFY.ok = true`。
