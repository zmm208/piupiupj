# v2.6 思考链（reasoning）不再显示

## 你贴的那段是什么
那是 DeepSeek 这类推理模型的 **思考链**，不是正文。它来自两个地方：

1. 接口里的 `choices[0].message.reasoning_content`（与 `content` 并列的字段）
2. 部分第三方中转把思考链**合并进 content**，用 `<thinking>…</thinking>` 之类包裹

App 只认 `content`，所以第一种不会显示；你看到的整段，说明你这家中转把它**塞进 content 里了**（或流式 delta 里也带）。

## 改法

### 1) 自定义请求一律非流式
```js
obj.stream = false;
```
非流式能一次拿到完整 JSON，我们就能**只取 content**、把 `reasoning_content` 整个丢掉；
然后再把正文合成为 SSE 流喂回 App，逐字效果完全不变。

### 2) 只取 content
```js
return m.content || '';     // reasoning_content 直接忽略
```

### 3) 标签式思考链清洗
```js
t = t.replace(/<(?:thinking|think)>[\s\S]*?<\/(?:thinking|think)>/gi, '');
t = t.replace(/<reasoning>…<\/reasoning>/gi, '');
t = t.replace(/<analysis>…<\/analysis>/gi, '');
t = t.replace(/<scratchpad>…<\/scratchpad>/gi, '');
t = t.replace(/<thought>…<\/thought>/gi, '');
```
另外还处理了两种常见前缀：
- 未闭合的 `<thinking>` 开头块（截到第一个空行）
- `思考过程：` / `推理过程：` / `reasoning:` 开头的整段

### 4) 测试对话同步清洗
「先测试一下连通性」的返回也走同一套 `ppCleanContent`。

## 效果

| 场景 | 之前 | 现在 |
|---|---|---|
| DeepSeek reasoner（独立 reasoning_content） | 正常 | 正常（本来就不显示） |
| 中转把思考链塞进 content | 整段思考链显示出来 | 只显示正文 |
| `<thinking>` 包裹 | 标签和内容都显示 | 全部剔除 |
| 流式 delta 里夹带 reasoning | 逐字吐出思考 | 已禁流式 + 只取 content |

## 备注
如果你那家中转把思考链和正文**混在一段纯文本**里、又没有任何标签，程序没法 100% 分辨。
那种情况下告我中转的名字，我给它单独加一条"按分隔线截断"的规则。
